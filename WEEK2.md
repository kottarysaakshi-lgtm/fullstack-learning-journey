
# Week 2 - Exploring JavaScript Programming

## Concepts Explored

- **Variable Declaration:** Practiced storing data using `let` and `const`.
- **JavaScript Data Types:** Explored different types of values, including strings, numbers, booleans, and objects.
- **Operators in Action:** Worked with mathematical calculations, comparisons, and logical expressions.
- **Decision Making:** Learned how to control program flow using `if-else` statements and ternary expressions.
- **Looping Techniques:** Practiced repeating tasks with `for` loops and controlling execution using `break` and `continue`.
- **Working with Functions:** Explored reusable code through regular functions, arrow functions, and callbacks.
- **Managing Data:** Practiced creating arrays and objects and retrieving their stored values.
- **Useful Array Operations:** Applied `map()`, `filter()`, and `find()` to process and search data.
- **Destructuring Techniques:** Learned simpler ways to extract values from arrays and objects.
- **Spread and Rest Syntax:** Practiced handling collections of values and working with function parameters.
- **Understanding Scope:** Explored variable accessibility in different parts of a program.
- **Value and Reference Behavior:** Studied how copying primitive values differs from copying object references.

## Skills Developed

Improved my understanding of JavaScript syntax, program execution, data handling, and logical problem-solving. Also learned to examine code carefully to understand how different statements affect the output.

## Coding Practice

- Attempted JavaScript MCQs to test my understanding of core concepts.
- Analyzed short code snippets and predicted their outputs.
- Reviewed explanations to identify mistakes and strengthen my programming fundamentals.

## Weekly Reflection

Week 2 helped me move beyond basic syntax and understand how JavaScript works in practical situations. The coding exercises improved my confidence in reading programs, understanding their behavior, and solving simple programming problems.
